# MOBALISTIC — MLBB AI Channel Engine

Автономный редактор русскоязычного Telegram-канала о Mobile Legends: Bang Bang. Режим публикации — **только сборки героев**.

## Что умеет проект
- Автоматически собирает свежие MLBB-материалы из RSS-поиска.
- Проверяет дату, источник, дубликаты и наличие ссылки на первоисточник.
- Использует Gemini только для редакторской переработки предоставленных фактов.
- Для сборок автоматически опрашивает live API, проверяет патч и шесть предметов, затем делает минимальную карточку: арт героя сверху, шесть иконок предметов снизу, без декоративных рамок.
- Получает рекомендации по сборкам из MLBBDex, сверяет шесть предметов с каталогом и собирает карточки с иконками предметов; при неполных данных сборка пропускается.
- Публикует изображение и читаемый HTML-текст одним сообщением Telegram (sendPhoto + caption), чтобы фото и текст всегда составляли один пост.
- Ведёт историю публикаций, журнал событий и ограничивает количество постов.
- Публикует только проверенные сборки героев; новости, мемы, киберспорт и текстовые заглушки не публикуются.\n- Подписи чередуют формулировки, используют живой русский язык, короткий игровой совет, эмблему и боевой спелл.\n- Номер сборки сохраняется в истории публикаций.

## Приоритеты контента
Мемы отключены: агент публикует только сборки, гайды/идеи, новости, киберспорт и ситуативные темы.

1. Сборки героев — главный приоритет (70)
2. Туториалы и игровые идеи (15)
3. Новости MLBB (8)
4. Киберспорт (5)
5. Ситуативные темы (2)

Числа задают относительный вес выбора, а не обещают точную долю каждого поста. Нельзя публиковать неподтверждённую сборку или выдуманные новости.

## Важно про сборки
Движок на каждом запуске опрашивает публичный API MLBBDex, сверяет шесть предметов с каталогом и ищет ещё не опубликованную сборку, ротируя героев. Если live API недоступен, используется только запасной реестр `data/hero_builds.json`. Патч, порядок предметов и ссылка на источник должны присутствовать до публикации.

Это **источниковые рекомендации по сборкам**, а не автоматически подтверждённые сборки конкретных pro-игроков. Агент не будет называть их «сборкой про-игрока», если источник не подтверждает такую связь. Результаты турниров и новости киберспорта собираются отдельно. Если текущий патч или каталог предметов не удаётся определить, сборка пропускается.

Карточка сборки не содержит лишних рамок и панелей: арт героя занимает верхнюю часть, а шесть иконок с названиями идут снизу в точном порядке источника. Подпись Telegram написана по-человечески, со сленгом и лёгким юмором; формулировки и короткий совет чередуются, чтобы посты не выглядели копиями. В каждом посте есть номер и роль героя, шесть предметов в порядке покупки, эмблема, боевой спелл и одно короткое предложение о том, как играть. Английский остаётся в официальных названиях героев и предметов. Пост публикуется одним сообщением: изображение + текст в подписи. Иконки загружаются из MLBBDex; в публикации указывается источник данных Mobile Legends Wiki (CC BY-SA) через MLBBDex.

## Установка
**Подробная пошаговая инструкция:** [SETUP_RU.md](SETUP_RU.md). Там перечислены точные ссылки и все три секрета, которые нужно добавить.

1. Создайте Telegram-бота через [@BotFather](https://t.me/BotFather).
2. Добавьте его администратором канала с правом публикации.
3. В GitHub откройте **Settings → Secrets and variables → Actions → New repository secret** и добавьте:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHANNEL_ID` (например, `@mobalistic`)
   - `GEMINI_API_KEY`
4. В **Settings → Secrets and variables → Actions → Variables** добавьте `PUBLISH_ENABLED` со значением `false`.
5. Запустите **Actions → Mobalistic AI Publisher → Run workflow**. В режиме `false` посты не отправляются; агент пишет предпросмотр в логи.
6. Проверьте логи и карточки в артефактах workflow.
7. Только когда проверили источники и тестовую работу, измените `PUBLISH_ENABLED` на `true`.

## Локальный запуск
Python 3.11+:
```bash
pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN="..."
export TELEGRAM_CHANNEL_ID="@your_channel"
export GEMINI_API_KEY="..."
export PUBLISH_ENABLED="false"
python -m src.mobalistic
```

## Настройка
- `data/feeds.json` — параметры источников; публикационный режим использует только сборки.
- `data/hero_builds.json` — проверенные сборки.
- `data/published.json` — журнал уже опубликованных материалов.
- `data/drafts/` — созданные карточки и предпросмотры.
- `PUBLISH_ENABLED=false` — безопасный режим без отправки.
- За один запуск публикуется максимум одна сборка; минимальный интервал между постами — 4 часа.

## Бесплатные ограничения
GitHub Actions и Gemini API имеют квоты/ограничения, которые могут меняться. Поэтому проект не обещает неограниченную бесплатную работу. При ошибке источника или AI публикация пропускается. Секреты нельзя коммитить в репозиторий.

## Контент и безопасность
Проект не скачивает и не перезаливает TikTok-видео автоматически. Для чужих роликов используйте ссылку и авторский комментарий. Новостная карточка всегда должна содержать первоисточник. Визуальная карточка не означает, что игровая сборка проверена — это определяется только данными каталога.
