# MOBALISTIC — настройка за 5 минут

## 1. Создай Telegram-бота
1. Открой @BotFather в Telegram и выполни /newbot.
2. Скопируй токен. Не отправляй его в чаты и не вставляй в код.
3. Открой настройки своего канала Mobalistic и добавь созданного бота администратором с разрешением публиковать сообщения.

## 2. Узнай ID канала
- Для публичного канала проще всего указать username с @, например `@Mobalistic`.
- Для приватного канала нужен числовой chat_id формата `-100...`. Его можно узнать через надёжный Telegram ID-инструмент после того, как бот добавлен в канал; не отправляй туда токен бота.

## 3. Получи Gemini API key
1. Открой https://aistudio.google.com/apikey и войди в Google.
2. Создай API key и скопируй его.
3. Доступность и бесплатные лимиты зависят от аккаунта, региона и текущих условий Google. Не включай платный биллинг, если не хочешь возможных расходов.

## 4. Добавь три GitHub Secrets
Открой https://github.com/Nullb1t-hub/Mobalistic/settings/secrets/actions и создай по одному секрету:
- `TELEGRAM_BOT_TOKEN` — токен от BotFather.
- `TELEGRAM_CHANNEL_ID` — `@username` публичного канала или числовой ID приватного.
- `GEMINI_API_KEY` — ключ Google AI Studio.

Секреты не добавляются в файлы репозитория. Не вставляй реальные значения в Issues, коммиты или обычные сообщения.

## 5. Оставь публикацию выключенной
Открой https://github.com/Nullb1t-hub/Mobalistic/settings/variables/actions и создай Repository variable:
- Name: `PUBLISH_ENABLED`
- Value: `false`

Затем открой https://github.com/Nullb1t-hub/Mobalistic/actions/workflows/publish.yml и нажми **Run workflow**. При выключенной публикации посты не отправляются. Открой завершённый запуск и скачай артефакт `mobalistic-preview-...` — там будут PNG-карточки и TXT-подписи.

## 6. Проверка перед запуском
- Проверь, что workflow завершился зелёным статусом.
- Проверь русские подписи, картинки и источники.
- Проверь, что бот — администратор и имеет право публикации.
- Проверь содержимое предпросмотра. В карточках сборок должны быть шесть настоящих иконок предметов.

Только после этого установи `PUBLISH_ENABLED=true`. Планировщик запускается примерно раз в 8 часов; время GitHub Actions может задерживаться. Каждый запуск ограничен двумя публикациями.

## Что бесплатно, а что нет
Код и карточки создаются бесплатно на GitHub Actions/Python, а данные MLBBDex доступны без API-ключа. Gemini API имеет лимиты и условия, которые могут меняться; поэтому абсолютную бесплатность и непрерывную работу гарантировать нельзя. Если AI-ключ не работает, агент завершится с ошибкой, а не станет придумывать новостной пост.
